Approval and validation gates

The page separates the human decision gate from the automated completion gates so implementation cannot accidentally start from the artifact alone.

approval gate

Stop here until the plan is approved.

No ENG-351 implementation chunks should run from this visual review. After approval, work begins at chunk 01 and proceeds in order. Before symbol edits, retry GitNexus impact analysis or record the unavailable-tool fallback required by the task status rules.

Operating notes

These guardrails come directly from the task file and keep the visual plan aligned with the implementation workflow.

Stable task IDs

Task IDs remain stable. Newly discovered defect-fix tasks should be added before editing implementation code.

Tests lead fixes

Do not weaken tests to match broken behavior. Fix implementation or record a blocker with the failing evidence.
