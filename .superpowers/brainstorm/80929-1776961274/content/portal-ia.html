MIC Portal Information Architecture

Shared fund-transparency screen, ledger-derived metrics, sidebar-to-full-page mortgage drilldown

Authenticated Route: mic.<domain>/portal
1. Fund Snapshot

Command-center style overview

Top-level derived metrics already available from the mortgage ledger.

Outstanding principal
Weighted avg yield / coupon
Active positions count
Weighted avg LTV
Maturity profile
Delinquency / arrears exposure
2. Exception / Focus Rail

What investors would care about first

Near maturities, delinquent positions, concentration spikes, and recent payment activity.

3. Positions Table

Real-time MIC holdings transparency

Every MIC-held mortgage position appears here with filters and sort.

Rows: mortgage, borrower/property summary, balance, yield, LTV, maturity, status, payment state, concentration markers
4. Detail Sidebar

Click a position

Sidebar opens first for fast inspection.

Mortgage summary, status timeline, latest payment signals, core ledger-derived facts
5. Payments / History

Recent scheduled, paid, missed, and overdue cashflow events tied to the MIC-held mortgages.

6. Exposure Views

Concentration by geography, borrower, property type, mortgage status, and maturity bucket where derivable.

7. No Personalization In V1

Same screen for every approved MIC investor until cap-table/personal allocation logic exists.

Position Drilldown Pattern
Table row click
↓
Right sidebar / mobile drawer
↓
Dedicated mortgage detail page with full history and related facts
Metric Philosophy
Use only current mortgage-ledger truth or clear derivations
Do not invent MIC treasury or cash-on-hand reporting from absent cash-ledger coverage
Bias toward maximum transparency from already-available system data
