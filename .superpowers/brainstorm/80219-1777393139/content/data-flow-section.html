Materialization Rules
  • Selected group → one Documenso envelope containing group templates
  • Standalone signable template → one Documenso envelope
  • Standalone non-signable template → generated PDF only
  • Static asset → static reference only
Runtime Context
  • mortgage, property, listing, borrower and broker graph
  • newly inserted deal row
  • lender name, system id, email/user projection
  • selected lawyer entry
  • selected fractions and computed investment amount
