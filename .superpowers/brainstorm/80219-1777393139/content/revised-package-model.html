Revised Model: Packages Compose Groups and Documents

Document groups stay focused on one Documenso signing envelope. A package is the higher-level deal-lock bundle containing multiple groups and standalone documents.

Conceptual hierarchy
Template
Single PDF layout
Fields + variables + signatories
Document Group
One signing envelope
N templates with compatible signatories
Deal Document Package
Full lock-time document bundle
N groups + N individual docs

Package Contents

G

Signing envelope group

Selected from published document groups. At deal lock, each group materializes as its own Documenso envelope.

S

Standalone signable document

A published signable template that does not need to share an envelope with other documents.

T

Standalone templated document

A non-signable generated document using package-wide variables.

P

Static PDF/document

An immutable asset included in the package without generation.

Implications

  • Keep existing Groups UI, but label it as signing envelope groups
  • Add Packages as a new higher-level tab
  • Package publish validates variables across all selected groups and standalone docs
  • Locked deal snapshots preserve package version, group versions, document versions, and generated envelope boundaries

Open decision

  • Whether standalone signable documents create one envelope each, or can be assigned into an ad hoc package envelope
