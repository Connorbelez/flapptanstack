Architecture Section

This is the proposed production document pipeline, with groups preserved as Documenso envelope units and packages introduced above them.

Document Engine Authoring
Variables
Canonical read-only + mapped custom variables
Templates
Versioned document layouts
Groups
One Documenso envelope definition
Packages
Versioned bundle of groups + standalone docs
Operational Application
Mortgage Files
Apply published package version future-only; allow mortgage-scoped overrides
Deal Lock
Newly inserted deal row supplies lender, lawyer, fractions, investment amount, mortgage graph
Deal Documents
Store immutable package snapshot and generated docs; link every row to deal detail

Core Contracts

  • Groups remain envelope-level and reusable
  • Packages are versioned standards, not signing envelopes
  • Mortgage package application is future-only
  • Locked deals snapshot everything needed for audit and regeneration diagnostics

Generated Outputs

  • One envelope per selected group
  • One envelope per standalone signable document
  • No envelope for static or non-signable generated documents
  • Published document views split template versions from locked-deal documents
