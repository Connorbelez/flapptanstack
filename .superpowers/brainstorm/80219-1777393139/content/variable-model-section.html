Variable Model Section

Variables become a production contract for what data exists at deal lock, not just an editable demo list.

Canonical
Read-only lock-time variables
  • Generated from a typed registry, not manually seeded rows
  • Visible in /admin/document-engine/variables
  • Available in the editor variable picker
  • Carry source path, type, nullability, description, sample value
Custom
Admin-created aliases
  • Allowed only when mapped to canonical source variables
  • Cannot invent unavailable data
  • Can provide business-friendly names and formatting
  • Publish validation resolves aliases back to canonical sources
